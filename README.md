# kalshi-calibration
## Data

One row is one yes/no bracket (market) on one month's CPI release, with a
threshold (e.g. "above 0.9%"), the actual reported value, and whether it
settled yes or no.

Example: `KXCPI-26SEP-T0.9` asked "Will CPI rise more than 0.9% in
September 2026?" CPI came in at 0.6%, so it settled **No**.
